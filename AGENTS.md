# Genesis Grove project instructions

Keep changes scoped and preserve existing saved-world compatibility. Run relevant
simulation and desktop checks before publishing. Delegate routine test execution
and result review to a lower-cost model when available, as requested by the owner.

The owner requests that every completed project update be uploaded to GitHub.
Push verified source changes to the public repository and publish versioned Mac
and Windows downloads for completed desktop releases. Verify uploaded assets and
the platform build results. Keep the repository public. Report any failed or
unfinished publication clearly; do not claim Windows gameplay testing from build
success alone.
